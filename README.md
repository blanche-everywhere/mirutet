# ミルテト

ミルテト学園のミルフィと、テトリミノの操作を学ぶデスクトップ向けのブラウザゲームシリーズです。現在のモード「フィネス編」では、最短の操作でミノを置く練習ができます。日本語UI・キーボード操作対応。オリジナルSVGイラストと合成効果音を使用します。

v2（2.0.0）でシリーズ名を「ミルテト」に改称しました。旧版の設定・キー・進捗・通算記録は、新しい保存先にデータ形式を変えず自動移行します（新しい保存先にデータがある場合はそちらを優先します）。保存キーのデータ形式は引き続き `.v1` です。

```sh
npm ci
npm run build
npm test
npm run test:browser
```

`index.html` または `dist/mirutet.html` をブラウザで直接開いてください。CSS・スクリプト・SVGはすべてインラインです。サーバー、ネットワーク接続、Webフォントは不要です。推奨画面は1280×720以上です。

レッスンは12ステップ。実演は実際の `InputHandler` で再生し、DASの長押しやIRS/IHSの出現時操作に合わせてキーが光ります。各ミノの最短表はエンジンのソルバーから生成します。チャレンジの成績は通常の練習記録に混ぜず、達成したレッスンを保存します。

ドリルでは破線が目標、薄いミノが着地点です。ホールドはスキップ扱いで、1種類だけ選んだ練習では無効です。最短入力で置くとPerfect、余分な入力があるとフォルト、違う場所ならミスです。ゼロフォルトでは最短成功するまで同じ目標に再挑戦します。スプリントは40・100・任意の配置数に対応します。タイマーは最初の操作から開始し、一時停止時間は除きます。ベストタイムは配置数ごとに保存します（練習条件による区分はありません）。

初期キー：←→ 移動、↓ ソフト落下、Space 固定、↑/X 右回転、Z 左回転、A 半回転、左Shift/C ホールド、R 同じ目標、N 次の目標、H ヒント、Esc 一時停止、`,` 設定。設定画面ですべて変更・追加できます。重複したキーは入れ替えできます。タイトルは矢印で選択・Enterで決定。実演レッスンはEnter/Space/→で次へ、←で戻り、Escでタイトルへ戻れます。

操作設定はスライダーと数値入力を同期して即時適用します。ARR=0はDAS完了時に壁まで移動、SDF=41は固定なしの瞬間落下、重力0は落下なしです。DCDは出現・回転・ハードドロップ後の自動横移動にだけ適用されます。左右同時押しは最後に押した方向が優先され、以前の方向のDASチャージも維持します。IRSは出現時に回転キーを長押し、IHSはARE中のホールド入力を使用します。

設定・キー・進捗・通算記録は `localStorage` の `mirutet-finesse.v1` に保存します。保存禁止の環境でも起動中は利用できます。設定だけJSONでコピー・貼り付けできます。不正なJSONや重複キーは適用前に検証します。音声が使用できない環境では無音で継続します。

ミノごとの音は、Web Audioだけで合成するオリジナルの短い合図です。設定の「ミノを音でお知らせ」で、NEXT（初期値）・現在のミノ・オフを選べます。NEXTでは、新しいミノが出現した瞬間にNEXTの先頭に来たミノの音が鳴ります。ドリル・スプリント・レッスンのチャレンジで共通です。実演はキューを進めないため鳴りません。同じ目標のリトライや自動再挑戦、キューが進まないホールド交換は無音です。空ホールドへの取り出しや、キューが進む出現時ホールド（IHS）は1回だけ鳴ります。

ミノの音量は0〜100（初期値60）で、全体の音量・効果音のオン／オフも反映します。I/O/T/S/Z/J/LのボタンをTabで選び、Enter/Spaceで試聴できます。タイミングがオフでも試聴できます。音声は最初のキー・ポインター操作で準備し、連続する合図は短くフェードして切り替えます。設定JSONの `ui.pieceCueTiming` と `ui.pieceCueVolume` に保存し、旧設定には初期値を補います。

| ミノ | 音の特徴 | 長さ |
| --- | --- | --- |
| I | 高い正弦波が880→1175 Hzへ滑らかに上昇 | 110 ms |
| O | 523 Hzに短い倍音を重ねた丸いベル | 145 ms |
| T | 659 Hzの三角波が柔らかく立ち上がる、短い高音のきらめき | 120 ms |
| S | 三角波で587→784 Hzの2音が上昇 | 125 ms |
| Z | 正弦波で740→554 Hzの2音が下降 | 125 ms |
| J | 349→330 Hzの低い三角波、短い倍音を添えた木琴風 | 135 ms |
| L | 440 Hzの三角波に遅れて660 Hzの正弦波が重なる | 150 ms |

実装は `src/engine.js`（DOMなし）、`src/audio.js`（合成音とキュー選択）、`src/mascot.js`（SVGと教材）、`src/app.js`（画面・入力・描画）、`src/style.css` に分離しています。ビルド時にマスコットの `MASCOT_CSS` をCSSへ組み込みます。内部座標はyが上向き、40行で、画面には20行と出現位置の2行を表示します。CanvasはDPR対応で、描画と入力には同じ `performance.now()` 時計を使います。OSキーリピートを無視し、一時停止やフォーカス喪失時にキーを解放します。

ソルバーは回転・タップ・DASを同じ1入力として幅優先探索します。着地セルの一致で対称形を同一視し、同点なら回転を先に選びます。空フィールドの配置数はI=17、O=9、T/J/L=34、S/Z=17。180°有効時の空フィールド全配置では最大3入力です（I/Oは最大2）。180°無効時はT/J/Lで最大4入力になり、両設定を独立参照テストで検証します。スタック上の意図的な下降を必要とする潜り込みはソルバーの探索対象外です。全表は `tests/finesse-table.txt` を参照してください。

`tests/browser.check.js` はplaywright-coreと `/usr/bin/google-chrome`（headless、`--no-sandbox`）を使用します。file://で起動し、コンソールエラー・ページ例外・外部通信を検出します。レッスン実演と練習、通常キー入力、Perfect/フォルト/ミス、DAS/ARR、実キー長押しによるARE・IRSの1入力判定、設定保存とJSON、キー競合のキーボード決定、一時停止、フィルター、短いスプリントと保存禁止時の動作を確認します。1280×720のタイトル・全12レッスン・ドリル・設定で文書全体のはみ出しを検査します。各レッスンの全実演とチャレンジで前後ボタンの矩形を測り、説明パネルをスクロールしてもボタン・盤面・マスコットが画面内に残ることを確認します。ドリルの各操作ボタン、設定の保存して戻るボタン、盤面下の列番号・説明の切れと文字サイズも確認します。ドリルは1920×1080での拡大も検査します。`screens/` にタイトル（title/menu）、通常レッスン、IRSレッスン、Tミノの最短表、固定前の目標、1080pドリル、成功、フォルト＋ヒント、設定、スプリント結果の11枚を保存します。title.pngとsettings.pngは保存テストとは別の新しいブラウザコンテキストで撮影し、CWの↑/X、ホールドの左Shift/C、DAS 110、ARE 80を確認します。トーストの自動消去と画面切替時の消去も検査します。ビルドのURL検査はSVG名前空間以外を拒否します。Chromeが起動できないサンドボックスでは、起動エラーを表示して失敗します。

ブラウザテスト用に `window.__mirutet.getState()`、`chooseTarget(type, {rot,x}, {delay})`、`dispatch(code, down)` を公開します。`chooseTarget` のxは占有セルの左端（0始まり）です。キーは通常の `KeyboardEvent` と同じ経路を通り、デバッグ操作で結果や入力数を書き換えません。

補助文字は13px以上、吹き出しは15pxです。レッスン盤面は列番号・キー・説明・結果欄の高さを実測して残りの高さに収めます。説明・実演切替・チャレンジ・長い最短表は細いパステル色のスクロールバーがあるパネル内でスクロールし、前後のレッスンボタンを下端に残します。設定項目もパネル内だけをスクロールし、保存して戻るボタンは見出しに残します。盤面からTabで操作欄へ移動でき、Tabをゲーム操作に割り当てた場合もShift+Tabで移れます。ダイアログはTab・矢印で選択し、Enter/Spaceで決定、Escで閉じられます。監査の根拠と修正一覧は [docs/REVIEW.md](docs/REVIEW.md) にあります。

## Ideas / memo

ユーザーのアイデア：盤面に影（目標）をあらかじめ示し、そこへ最適な入力手順でミノを置く、パズル形式の練習。現在のドリルは「目標の影を見る → 最短入力で置く → 手順を振り返る」という基本ループをすでに実装しています。積まれたブロックから始める問題や、複数ミノを使う専用のクイズ／「問題」モードは今後の検討事項です。今回の実装範囲には含めません。

Idea: pre-show a target shadow and place the piece there with the optimal input sequence. The current drill already implements this core loop; a dedicated quiz mode with a pre-filled stack and multiple pieces is future work.

前髪は「設定 → 共通の見た目」で 7:3・真ん中分け・控えめインテークから選べます。初期値は真ん中分けです。選択は全画面に反映され、既存の表示設定と一緒に自動保存・JSON入出力されます。古いデータで選択がない場合や未知の値は真ん中分けになります。記録・進捗・キー設定は維持します。保存不可環境では起動中のみ選択を保持します。

`npm run test:appearance` は本体で前髪切替・保存・入出力・各画面・キーボード操作・保存不可環境を検証します。ブラウザテストは `CHROME_PATH` でChrome実行ファイルを指定できます（未指定は `/usr/bin/google-chrome`）。

衣装は同じ共通設定で制服／黒ケープから前髪とは独立して選択できます。初期値と不正値のフォールバックは制服です。衣装も表示設定 `ui.outfitSkin` に保存され、JSON入出力に含まれます。前髪は `ui.hairSkin` に保存されます。読み込み時はミノの音と見た目の初期値を補い、正規化したプロフィール全体を保存します。すべての設定の初期化で、音と見た目も初期値に戻ります。

## English

An offline, Japanese tetromino practice game series with original mascot ミルフィ. The current mode, フィネス編, teaches minimum-input placement. Run `npm run build`, then open `dist/mirutet.html` directly. Everything is inlined; no server or network is required. `npm test` runs the independent engine/mascot checks. `npm run test:browser` runs system Chrome through playwright-core and saves screenshots in `screens/`. The current mode includes engine-driven lessons, filtered drills, sprint, handling/key settings, persistent statistics, and synthesized audio with graceful fallbacks.
