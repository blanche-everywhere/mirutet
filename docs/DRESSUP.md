# ミルフィのきせかえ（BL-98）

メニューの「ミルフィのきせかえ」から専用ページを開きます。ヘッダーからも移動できます。中央のミルフィを見ながら、髪型と衣装のサムネイルを選択すると即時反映・自動保存されます。

| 内部ID | 表示名 |
| --- | --- |
| side | そよ風サイド |
| center | おすましセンター |
| intake | ふんわりフェザー |
| uniform | 放課後フィネス |
| cape | 月夜のワルツ |

既存の `ui.hairSkin` / `ui.outfitSkin` を共有し、記録・進捗・音・キー設定を保持します。設定JSONの入出力と旧データの正規化も従来どおりです。設定画面の既存選択欄とも同期します。保存できない環境では起動中だけ保持し、ページ内に案内を表示します。

5表情の試し表示と動きの停止はページ内だけの状態です。ゲームのコーチ表情や保存データには入りません。「戻る」またはEscで元の画面に戻ります。練習中の移動ではキーを解放し、音を止め、セッションを一時停止します。戻った後はポーズ画面から明示的に再開します。タイトルへ移動した場合は従来どおり練習を終了します。

`npm run test:dressup` は生成済み本体HTMLをChromeで開き、全6組み合わせ・全5表情、瞬き、保存と再読み込み、連打、キーボード、練習中の誤操作・音の抑止、往復、390px幅、旧データ・不正値・保存失敗を確認します。`CHROME_PATH` で実行ファイルを指定できます。
