# BL-144: 採用した怒り表情

ミルフィの表情として `angry`（表示名「むっ」）を追加しました。
着せ替えルームの表情ボタンと `node tools/render-mascot.js` の一覧で確認できます。
描画APIは `MiruTet.mascot.mascotSVG('angry', options)` です。

採用済み比較プレビューのA案をそのまま使用しています。寄せた眉・半目・頬、元の
`sorry` と同じ口、こめかみの4本に分かれた怒りマークを組み合わせました。
マークは顔と同じ `mirufi-bob` 内にあり、頭の動きに追従します。
前髪3種と衣装2種を維持し、他の表情にはマークを出しません。

怒りの新しいゲーム内発火条件は追加していません。ミス時は従来どおり `sorry` です。
着せ替えでの表情選択は従来どおりその訪問中だけで、ゲームの反応を変更しません。

## 検証

`npm run test:angry` は、実装前に採用済みプレビューから取得した
`tests/fixtures/angry-approved-v2.json` と、ビルド済みHTMLの描画を比較します。
基準はLibrary `libfile_feda2187fe348191b13b1e24a8a97f41` version 2です。
fixtureを変更後の描画から再生成して一致させないでください。

- 6組合せ × 7条件の画像比較（300px幅、150px幅、320px高、移動中・瞬き中）。
  アンチエイリアスの丸め誤差として各色チャンネル最大1/255のみ許容。
- 全表情との往復切替でマークの残留・重複なし。
- 瞬き8時点と、顔に対するマークの位置が一定であること。
- 自動アニメーション、キーボード選択、390px幅、動きを減らす設定。
- 外部通信とブラウザエラーなし。

既存の単体テスト・ブラウザ検証も併用します。
